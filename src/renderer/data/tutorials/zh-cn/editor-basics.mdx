# 编辑器基础

编辑器支持 AlphaTex 的日常文本编辑，预览面板提供即时反馈。

## 编辑功能

- 基本文本编辑
- 自动保存行为
- 语法高亮
- 项目工具链带来的轻量格式一致性

## 与预览协同

- 让编辑器和预览并排显示。
- 做小改动并持续验证渲染。
- 用播放控制验证节奏和时值。

## 快捷键

- `Ctrl+Z` / `Cmd+Z`: 撤销
- `Ctrl+Y` / `Cmd+Y`: 重做
- `Ctrl+S` / `Cmd+S`: 保存
- `Ctrl/Cmd+O`: 打开文件切换器
- `Ctrl/Cmd+Shift+P`: 打开全局命令面板
