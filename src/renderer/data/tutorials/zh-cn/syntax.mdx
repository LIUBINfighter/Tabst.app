# 注释

如果你把 alphaTex 与编程语言或脚本语言相比，你会发现这门语言中有类似的结构。alphaTex（顾名思义）借鉴了 LaTeX 的一些方面，LaTeX 是一种知名的文档编写语言。随着 alphaTex 的发展，它衍生出了本文介绍的多种自有语法结构。

将 alphaTex 保存到文件时，我们建议使用 `.atex` 文件扩展名。

## 注释

注释支持 C 风格语法：`// 单行注释` 和 `/* 多行注释 */`。你可以在 alphaTex 文件的任何位置使用注释，为所写文档做进一步的结构化或组织化标注。

## 字符串

文本值用带引号的字符串表示，与大多数编程语言类似。单引号和双引号都支持。

* `"Double Quoted String"`
* `'Single Quoted String'`

此外支持以下转义序列：

* `\n` 换行
* `\r` 回车
* `\t` 制表符
* `\uXXXX` Unicode 字符，其中 XXXX 是 4 位十六进制数字。
* `\\` 反斜杠
* `\'` 或 `\"` 引号字符

## 数字

alphaTex 支持整数和小数。小数只允许在特定的地方使用，以避免与其他语法结构产生歧义。

示例：

* `10`
* `-10`
* `0.5`
* `-4.5`

## 参数 / 实参列表

许多地方使用参数来描述诸如拍号或推弦点之类的值。
如果有多个值，实参应该用括号 `(values)` 包裹。如果只有一个值，括号可以省略。

单个值可以是：

* 整数：`3`、`-10`
* 小数：`3.3`、`-10.5`
* 字符串：`"Hello"`、`'Hello'`
* 特殊标识符：`true`、`hide`、`x`

基础示例

* `( 1 2 3 )`  数字列表
* `("Test" 3 hide)` 混合类型的值列表

真实示例

* `\ts (3 4)` 3/4 拍号（在小节级别指定）
* `12.2 { b (0 4 0) }` 描述全音推弦并释放的推弦效果
* `\title ("Song Title" "Title: %TITLE%" left)` 显示为左对齐的 `Title: Song Title`

你可以把这个语法结构比作脚本或编程语言中的函数调用：`myFunction(value1, value2)`。alphaTex 的区别在于，各个实参之间用简单的空格分隔，且单实参调用不需要括号。

## 属性

属性是一组键-值列表对，用于描述元素的可选附加方面。
它们用来给音符和节拍添加效果、控制谱表中显示哪些标记等。

属性总是用花括号包裹。属性以描述属性的标识符开头，其后可选地跟一个值列表作为其值。

示例：
* `\track "Track Name" { color "#FF0000"}`
* `\staff {score}`
* `C4 {b (0 4) v txt "Bend with Vibrato"}`

属性标识符不区分大小写。

## 元数据标签

元数据标签是与 LaTeX 最相似的结构。元数据用于描述数据模型中的各种元素。

元数据标签的主要语法是：`\tag parameters {properties}`。
从语法角度看，`parameters` 和 `{properties}` 都是可选的。根据 `tag` 的不同，可能要求指定某些值。

示例：

* `\title "Song Title"`
* `\track "Track Name" {color '#FF0000'}`
* `\ts (3 4)`

元数据标签标识符不区分大小写。

### 元数据标签参数

元数据标签可能接收一个或多个值作为实参。支持的具体值（必填或可选）取决于标签本身。
详见上面的[实参](https://alphatab.net/docs/alphatex/syntax#parameters--argument-lists)一节。

### 元数据标签属性

元数据标签可能有一个或多个属性。支持的具体值取决于标签本身。
详见上面的[属性](https://alphatab.net/docs/alphatex/syntax#properties)一节。
