# 快速开始

欢迎使用 Tabst！本指南带你从打开应用开始，一直走到写出并播放你的第一份乐谱。

## 基础操作

Tabst 是围绕 AlphaTex（一种纯文本记谱格式）构建的吉他谱编辑器。你可以在左侧编辑文本，在右侧看到渲染出的乐谱。

## 典型工作流

1. 新建或打开一个 `.atex` 文件。
2. 在编辑器中输入 AlphaTex 内容。
3. 实时预览乐谱渲染。
4. 调整播放设置并点击播放。
5. 以文本优先的方式快速迭代。

## 示例

```alphatex
\title "Sample Track"
\time 4/4
\key C
.
:4 0.3 2.3 3.3 5.3 |
```

## 提示

- 从小乐句开始，逐小节构建。
- 用元数据让你的文件更易检索。
- 保持文件简洁、可移植，便于分享和版本管理。
