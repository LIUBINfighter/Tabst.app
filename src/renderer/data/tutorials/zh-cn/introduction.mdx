# 介绍

在本节中，你可以找到用 AlphaTex 编写音乐记谱的所有细节。
AlphaTex 是一种为 AlphaTab 编写音乐记谱的文本格式。可以通过设置
[`tex`](https://alphatab.net/docs/reference/settings/core/tex) 选项，或调用 API 上的
[`tex()`](https://alphatab.net/docs/reference/api/tex) 方法来启用 AlphaTex 加载。
AlphaTab 会从元素内容中加载 tex 代码并解析。你也可以像其他格式一样从文件中加载。
AlphaTex 支持 alphaTab 支持的大部分功能。
如果你发现缺少想要的功能，欢迎
[在 GitHub 上发起讨论](https://github.com/CoderLine/alphaTab/discussions/new)，我们一起寻找合适的解决方案。
