# AlphaTeX 教程

AlphaTeX 是一种基于文本的记谱语言，用于编写可演奏的乐谱。

## 基础语法

AlphaTeX 将指令（元数据、轨道设置、渲染行为）与音符表达式结合在一起。

```alphatex
\title "Example"
\tempo 96
.
:4 0.3 2.3 3.3 5.3 |
```

## 核心积木

- 乐谱元数据：标题、副标题、速度、调号、拍号
- 结构指令：小节、反复、分节
- 音符与时值：品格/弦、和弦、节奏单位
- 效果与演奏法：推弦、滑音、重音、力度

## 写作策略

1. 先写元数据和拍号。
2. 先录入一个乐句。
3. 验证播放效果和可读性。
4. 再补充效果与标注。

## 何时使用 ATDOC

用 ATDOC 注释设定文档级默认值（显示/播放器/打印/元数据），需要时再到界面里微调。
